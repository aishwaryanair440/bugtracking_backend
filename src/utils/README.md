# utils/

This folder contains **utility/helper functions** — small, reusable pieces of code used across the project.

## Example helpers you might add later
- `formatDate.js` — format date strings consistently
- `generateId.js` — generate unique IDs
- `validateInput.js` — reusable input validation helpers

These functions do not belong to any single feature. They are general-purpose tools used by controllers and services.
